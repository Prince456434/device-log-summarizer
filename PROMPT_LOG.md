# PROMPT_LOG.md — AI-Assisted Chart Generation Log

This file documents the AI-assisted workflow used to develop `chart_generator.py`.

---

## 1. Initial Prompt

> **Prompt sent to AI assistant:**
>
> "Write a Python function `generate_temperature_chart(json_path: str, image_path: str) -> None`
> that reads a JSON file containing a `devices` list — each item having `device_id` and
> `average_temperature` fields — and produces a bar chart PNG saved at `image_path`.
> Use matplotlib with the Agg backend. Include a title, axis labels, and save with
> `tight_layout()`. Handle missing files and empty device lists gracefully."

---

## 2. Issue Identified in Initial Draft

The initial draft generated the chart but had **overlapping x-axis labels** when more than
three or four device IDs were present. Because device labels were long (e.g. `DEV_ALPHA`,
`DEV_BRAVO`) and were rendered horizontally at the default angle, they collided and became
unreadable.

Additionally, the first draft did **not annotate each bar with its numeric value**, making
it hard to read precise temperatures from the chart at a glance.

---

## 3. Follow-up Prompt

> **Corrective prompt:**
>
> "The chart has two problems:
> 1. X-axis device labels overlap when there are more than four devices. Please rotate them
>    30 degrees (right-aligned) when `len(device_ids) > 4`, and leave them horizontal
>    otherwise.
> 2. There are no value annotations above each bar. Add a text label showing the
>    temperature rounded to two decimal places, positioned slightly above the top of
>    each bar, centred horizontally."

---
